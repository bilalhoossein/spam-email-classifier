
# Spam Email Classifier

A beginner Machine Learning project using Supervised Learning
to classify emails as Spam or Not Spam.

## Technologies
- Python
- Scikit-learn
- CountVectorizer
- Multinomial Naive Bayes

## How it works
1. Train the model using labeled email examples.
2. Convert email text into numerical features.
3. Learn patterns using a classification algorithm.
4. Predict the category of a new email.

## Installation

```bash
pip install -r requirements.txt
```

## Run the project

```bash
python spam_classifier.py
```

- Supervised Learning
- Classification
